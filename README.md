# Space Combat AI

A Unity space combat project made for the Games Programming: A.I. and Physics Automaton Gym assignment.

## Features

- AI boids with flocking, separation, alignment and cohesion.
- Adaptive attack groups that take turns approaching and strafing the player.
- Player-controlled ship movement, boosting and rolling.
- Mouse aiming and projectile shooting.
- Health, damage and death particle effects.
- Physics-based movement and collision detection.

## How to Run

1. Clone or download the repository.
2. Open the project in Unity Hub.
3. Open the main scene and press Play.

## Controls

- **WASD:** Move and turn the ship
- **Q / E:** Roll
- **Shift:** Boost
- **Ctrl:** Slow down
- **Left Mouse Button:** Shoot
- **Tab:** Switch between flight and shoot modes
- **V:** Switch camera view
